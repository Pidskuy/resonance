# Resonance

A macOS music player for local files that plays lossless and hi-res audio at its real quality: the DAC is switched to each track's own sample rate, playback is gapless, and a bit-perfect badge shows when the signal reaches the DAC untouched.

Built with Python (sounddevice, soundfile, mutagen, SQLite) and an HTML/Alpine.js interface in a native window (pywebview).

**Status:** in development. See `PLAN.md`.
